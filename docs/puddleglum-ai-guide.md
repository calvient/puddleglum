# Puddleglum AI Guide

This package is used to generate TypeScript that mirrors a Laravel backend. The useful behavior is not an isolated PHP string helper; it is whether a Laravel app can run `php artisan puddleglum:generate` and receive stable, usable TypeScript files.

## Core Files

- `src/PuddleglumGenerator.php` orchestrates discovery, generation, file sync, and `utils.ts`.
- `src/Generators/ModelGenerator.php` generates model interfaces from schema columns, Eloquent relations, relation counts, and accessors.
- `src/Generators/RequestGenerator.php` generates request interfaces from FormRequest validation rules.
- `src/Generators/ApiRouteGenerator.php` generates Axios classes from routes that use the `api` middleware.
- `src/Definitions/TypeScriptProperty.php` and `src/Definitions/TypeScriptType.php` model TypeScript properties and primitive mappings.
- `src/Support/TypeScriptFormatter.php` centralizes output indentation and avoids rewriting files when content is unchanged.

## Test Strategy

Use `tests/Feature/GeneratePuddleglumTypesTest.php` as the template for future tests. It creates a temporary Laravel-like app with:

- Eloquent models and relationships.
- A FormRequest with scalar rules, nested object rules, nested array rules, file rules, `exists`, `confirmed`, nullable fields, and optional fields.
- API routes for GET, POST, route model parameters, no-body DELETE requests, `GlumRequest`, and `GlumResponse`.
- Golden TypeScript files under `tests/Fixtures/Expected/puddleglum`.

When behavior changes, update the fixture backend first, run the test to see the generated delta, then update the golden files only if the new output is the intended package behavior.

## Commands

```bash
./vendor/bin/testbench package:test --no-coverage
composer test
composer stan
```

Use the Testbench command for targeted local verification because the PHPUnit XML includes coverage configuration and this local environment may not have a coverage driver.

## Edge Cases To Keep In Mind

- `PuddleglumGenerator` reads `composer.json` from the current working directory. Tests that exercise full generation should `chdir()` into a fixture root and register an autoloader for fixture classes.
- Only routes with `api` middleware are generated by `ApiRouteGenerator`.
- `GlumRequest([])` is different from no `GlumRequest` attribute; keep null checks strict.
- Laravel schema metadata differs by database driver. SQLite can report JSON columns as string-like columns in tests.
- New-style Eloquent `Attribute` accessors do not expose their returned value type at runtime, so they currently generate `any`.
- Generated output order should be deterministic. Sort discovered classes/namespaces before rendering.
